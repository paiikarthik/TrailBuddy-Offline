      🌱 About TrailBuddy Offline & Hacktoberfest 2026

      TrailBuddy Offline was built for Hacktoberfest 2026 Week 1 Challenge: “Touch Grass”. The average modern adult spends over 7 hours every day looking at illuminated digital screens. The Touch Grass challenge invites open-source developers to build software whose ultimate success metric is people closing the app and engaging with the physical natural world.

      🏗️ Architecture & Privacy Design

      📴 Offline-First PWA: Full Service Worker caching with Web App Manifest. Once loaded, the core app shell, rule-based planner, challenges, and nature journal work seamlessly in dead zones with zero cell signal.
      🔒 Zero-Cloud Nature Journal: Your observations and thoughts belong to you. Entries are stored strictly in browser storage with one-click JSON backup and restore. Zero tracking or cloud harvesting.
      🤖 Open-Weight AI Integration: Powered by local Ollama (Mistral / Llama) or hosted open-source inference endpoints. Always falls back smoothly to deterministic rule-based planning if models are unavailable.

      ⚙️ Running Open-Source AI Locally (Ollama)

      TrailBuddy supports genuine local AI inference without paid third-party APIs. To run an open-weight model locally on Windows, macOS, or Linux: 

      # 1. Install Ollama from https://ollama.com
# 2. Pull an efficient open-weight model:
ollama pull mistral
# or a compact model:
ollama pull llama3.2

# 3. Ensure Ollama is running (defaults to http://localhost:11434)
# 4. TrailBuddy will automatically detect it and generate AI plans!

      ☁️ Render Deployment & Cloud Inference

      On public Render Web Service deployments, running large language models in-memory exceeds free container RAM limits (512MB). TrailBuddy gracefully handles this by:

      • Defaulting to the high-performance Rule-Based Engine on Render when AI variables are not configured.
      • Supporting external open-weight endpoints via HOSTED_AI_ENDPOINT (e.g. HuggingFace TGI or vLLM server).
      • Transparently reporting active generation source on every plan.
